以当前正式安装的P0前运行逻辑回退版为基线，合并上一轮和本轮修改。仓库此前最高版本V0.7，因此升为V0.8；没有重新引入P0后诊断、版本检测和放球行为变更。故障根因仍未确认。

- 新增侧栏“分担设置”，第1/2/6次按怒气或时间设置；怒气60–99整数；时间接受24.756、3:21、3：21、分:秒小数。无效输入不保存、不发送。
- 第3/4/5次时间和怒气均不可手动修改；时间锁定151/202/278秒，显示“（不推荐更改）”。目标怒气反算并四舍五入成整数。
- 默认六轮时间25/75/151/202/278/329秒，目标70/94/96/96/96/96，集合提醒提前6秒。
- 第1/2/6次提示为“集合分担→开关看能量→2→1”，取消3和进；第3/4/5次保留原4321进。
- 原中上文字下方60像素显示Boss主资源实时值；集合到预计分担后5秒显示当前/目标，之后恢复当前值。
- 估算只使用设置值，未比较或计算实时秘密能量；不按实际分担事件自动纠正时间，可能因实战提前或延后产生偏差。
- 第1次t=(E-20)/2；第2/6次t=前次预计t+3+E/2。固定轮次3/5反算E=2*(t-前次t-28)，第4次用3秒偏移。目标整数为最近整数；时间等价于<60、>=100或四舍五入到100时拒绝。
- 第3/4/5次反算怒气原始估算和取整值都必须小于100，超出时整份配置拒绝保存和发送；第三次不固定98但151秒固定。因此第2次必须晚于73.25秒；六轮都不能等于100；1/2/6输入仍限60–99。第1、2轮的单项60虽属基础输入范围，但其与可用前后轮组合无法满足第三轮上限，联动校验会拒绝。
- 团长脱战手动保存并发送；团员脱战接收并保存，战斗/测试中拒绝；成员需同协议新版本。独立SFD_SOAK前缀，不改原风向消息，不依赖MRT，不发团队可见聊天。
