# SFD 分担配置协议 1

前缀：SFD_SOAK；频道：RAID或INSTANCE_CHAT，仅团队当前团长，脱战发送/接收。风向旧协议独立，不更改。

载荷：`1|revision|mode1|value1|mode2|value2|mode6|value6`

mode E=整数目标怒气，T=开怪后绝对秒数。只同步1/2/6轮；3/4/5由本机锁定时间和同一公式推导。数值按17位有效数字串行化，保留小数时间。revision=发送时间毫秒级值，重复发送确保单调递增；同一团长小于等于已接收序号的消息丢弃，自身发送立即记录序号防止延迟回传覆盖。2秒发送间隔。

收到消息后完整校验版本、字段数、数值和60–99范围，以及固定3/4/5轮反算怒气<100且取整结果<100后，再原子应用全部配置；未知协议/非团长/其他频道/非法/重复/晚到/战斗或回放消息不应用，不积压到下一场。序号记录在本次客户端会话中，不建立持久消息历史。
跨服按完整角色名和规范化服务器检查身份；本服简写补上本服名，不把异服同名当团长。
新加入或战斗中漏收的成员需要团长脱战重新发送；当前没有确认回执、自动请求或成员安装状态检测。
旧版不支持这个前缀，不会应用新设置；混用时不能保证相同集合时间。需要所有使用集合提醒的成员安装同一协议版本。

每次SFD配置拒绝本地print具体原因。第3/4/5次时间和怒气不可手动改，反算及取整值均小于100。
