# Sszorak Fixed Direction · v0.5

输入 `/sfd` 或 `/m5` 打开设置。

## P0 修复与诊断

真实点名继续使用旧 DFT 2026.09.11 的分类、识别窗口和 slot 锁；未扩窗。
个人放球提示改为成功显示后持续配置时长（默认11秒），随后0.5秒淡出，不再被固定爆炸时间拒绝或提前清除。若新的个人提示到来，仍按当前 SFD 行为替换旧提示，并记录 ASSIGNMENT_REPLACED。
severity / duration 为 Secret 时安全拒绝，记录 SECRET_CLASSIFICATION_FIELDS；不降级为只看时间的识别。其余不命中窗口记录 NO_WINDOW。
已恢复囊肿前“囊肿准备，面对BOSS”提醒。

诊断自动保存在 SszorakFixedDirectionDB.diagnostics，最多10场、每场300条；正式战斗标 RAID，脱战测试标 TEST。超限丢弃最旧记录，droppedEvents 表示已裁剪数量。
`/sfd diag status` 查看保存场次、最近编号、事件数和版本；`/sfd diag clear` 清空记录（之后下一场重新记录）。
出现漏提示或提示变化后，正常 `/reload` 或退出游戏，再发送以下文件给团长：

`WTF\Account\<账号目录>\SavedVariables\SszorakFixedDirection.lua`

不需要复制文本框。编号 warningSequence / assignmentSequence 均为每场本地递增编号；覆盖事件附带前后 slot、编号、显示时间与间隔，不记录前三点 marker identity。
完整基线、例外和离线测试见 `audit/P0_AUDIT.md`。未声称通过真实客户端 Secret/团本验证。

## 放球与罗盘

先面对BOSS，再按罗盘寻找放球图标。每轮选择三个风向，囊肿放在风向对面；第四个放球点在BOSS脚下。实际点名后显示“去【标记图标】放球”。
罗盘转向星星的时间为00:44.5、02:51.5、04:58.5，坦克带位提示保持原时间。
负责看风的玩家自行开启发送端，每轮只点击三次，避免同时开启两套发送端。

## 毒蛇之怒

已取消“记住标记位置”的文字与语音。
开关目标时间：24.5、75、151、202、278、329.5秒。六轮完整采用DFT集合分担时间轴基准。
每轮毒蛇之怒前6秒显示“大团进”、播报“集合分担”；前4秒显示“开关：4”、只播报“开关”，随后依次播报“3、2、1、进”。结束1秒后隐藏。
提醒默认显示在屏幕中上方。常规页可开关此提醒。

## 调整位置

位置设置 → 文字提示：进入编辑后分别拖动原文字提示与“毒蛇之怒文字”的绿色条，点齿轮调整字号和对齐。两者位置分别保存。
罗盘、发送面板及接收条也可在位置设置中调整。

## 脱战测试

测试页选择职责和速度，开始后运行00:00至06:30；支持暂停、继续、停止、重新开始和跳转。
查看首轮毒蛇之怒：跳转00:18后继续，建议使用1倍速听倒计时。
近战治疗包括奶骑、奶僧；模拟放球只针对远程DPS和远程治疗。毒蛇之怒提醒不受此放球职责筛选影响。
测试发送与接收不会发送团队消息。进入战斗后自动停止测试。

## 语音

本版本继续使用游戏内置 TTS，无需安装额外语音包。

## BOSS图标

位置设置 → 罗盘：预览 / 拖动 / 大小 → BOSS图标透明度，可单独调节，0为隐藏。
图标位于场地标记下层，默认65%。跟随既定带位时间轴显示月亮、星星、中场位置。
短动画表示预定带位方向；到星星后保持该方向，随罗盘旋转一起转向12点。图标不是实时位置探测。
中场图标位于圆心，不改变第四放球点或延后旋转时间。
