# Sszorak Fixed Direction — V1.0

支持《魔兽世界》12.1.5（Interface 120105）。保留战术罗盘、Boss 图标、Boss 能量显示和位置设置。

罗盘按原有固定时间轴运行。Boss 图标从中场回到月亮时，同一 anchor 事件同步将月亮转到上方；不是实时 Boss 位置检测。前两次囊肿爆炸结束后再转星星朝上，第三、第四次点名到爆炸结束期间保持星星朝上。图标显示预设走位方向，使用时请先面向 Boss。

输入 `/sfd` 或 `/m5` 打开位置设置，可分别调整罗盘、Boss 图标透明度和能量值显示位置。保留现有存档；分配、点名收发、分值配置、团队同步、文字语音提醒和内置战斗测试继续停用。

## V1.0 更新

- 修复第二、第三周期 Boss 图标回月亮时，罗盘没有同步恢复月亮朝上的问题；复用原版 SetAnchor 联动和127/255秒预设，不另外设置复位时点。
- 补齐开战初始化、结束和重开时的朝向与动画状态重置；保留中场角度、八标记和 Boss 图标动画。
- 保险调整：转星星的预设余量从第二次爆炸参考时间后0.5秒增加至1.5秒，对应45.5/172.5/299.5秒。这与月亮复位缺陷分别处理。
- TOC 版本升级 V1.0，声明12.1.5接口120105。第三周期末341/343秒的旧 expiry 参考未改：它们不驱动当前罗盘转向，精简模式也不执行该分配清理事件。

## 验证与安装

已通过离线 Lua 5.1 模拟的完整三周期、两组囊肿禁转窗口、月亮/星星朝向、Boss 图标、中场保持角度、灭团重开及结束重置回归；未将离线测试称作实战验证。固定时间轴无法保证任意掉帧、卡顿或后续战斗时序变更下的实际余量。

解压后将 SszorakFixedDirection 文件夹安装到 AddOns。发布操作本身不覆盖正在使用的游戏目录；下次安全加载后请确认真实客户端渲染、复位联动、能量值显示和既有位置设置。
