# Sszorak Fixed Direction · V0.8

输入 `/sfd` 或 `/m5` 打开设置。

## 放球与罗盘

先面对BOSS，再按罗盘寻找放球图标。每轮选择三个风向，囊肿放在风向对面；第四个放球点在BOSS脚下。实际点名后显示“去【标记图标】放球”。
罗盘转向星星的时间为00:44.5、02:51.5、04:58.5，坦克带位提示保持原时间。
负责看风的玩家自行开启发送端，每轮只点击三次，避免同时开启两套发送端。

## 毒蛇之怒

已取消“记住标记位置”的文字与语音。
每轮毒蛇之怒前6秒显示“大团进”、播报“集合分担”。第1、2、6次前4秒显示并播报“开关看能量”，随后只显示和播报“2、1”，没有“进”。第3、4、5次保留原来的“开关4、3、2、1、进”。
提醒默认显示在屏幕中上方。常规页可开关此提醒。

## 分担设置与团队同步

左侧新增“分担设置”：第1、2、6次可以按目标怒气或分担时间设置，保存后用于下次开怪。怒气必须是60–99整数；时间接受秒数（如24.756）或分:秒（如3:21、3：21），换算后的目标怒气显示为最近整数，超范围不保存、不发送。
第3、4、5次时间固定为151、202、278秒，时间和怒气都不可编辑，旁边标有“（不推荐更改）”；目标怒气根据上一轮时间反算，三轮原始估算及取整结果都必须小于100，否则整份配置拒绝保存和发送。
默认分担时间为25、75、151、202、278、329秒，默认目标怒气为70、94、96、96、96、96。第3次怒气不固定为98，但不能等于或超过100，因此第2次必须晚于73.25秒；不满足联动条件的配置不保存、不发送，固定时间保持不动。
时间估算使用每秒约2点怒气：第1次为(目标-20)/2，第2、6次为上一轮预计时间+3+目标/2，第3、5次反算时使用28秒偏移，第4次使用3秒偏移。实际分担事件不会自动校正这套预定时间表。
团长脱战时点击“团长：保存并发送”，通过SFD独立插件消息同步设置。团员需要V0.8或支持同一协议的版本；只接受当前团长的团队消息，战斗和测试期间不接受修改。旧版不会接收这项设置。此功能参考MRT通信方式，无需安装MRT，不占用团队聊天；原来的风向收发格式未改变。
每次拒绝分担配置的预览、保存、发送或接收都会在本地聊天窗口print具体原因；面板也保留输入或发送错误提示。不打印受保护实时能量及原始消息。

## 最近100场日志

新增独立SessionLog观察记录器，在存档sessionLogs中分别保留最近100场实战和100场测试；测试不会挤掉实战。旧diagnostics原表保持原样，已有记录只复制到新分类索引。每场事件上限沿用300，超出记录droppedEvents计数。
记录真实开怪/结束入口、警告事件、风向接收序号、状态变化、提示请求/清除和战斗中的配置拒绝。不读取或记录警告载荷、风向秘密值、Boss实时能量；提示请求日志不等同于客户端实际显示成功。记录器只观察，不改旧版点名/位置分配逻辑。输入`/sfd log`查看留存数量；没有清空命令。
现有存档和.bak已完整备份，本次不直接写存档文件，也不通过/reload覆盖证据；新日志由游戏正常保存机制持久化。

## BOSS能量值

原毒蛇之怒文字下方一行实时显示boss1主资源的当前能量。每轮集合提醒开始显示“当前值 / 本轮目标值”，预计分担时刻后5秒恢复为单值；结束战斗或离开副本隐藏。
实时能量直接交给文字接口显示，不参与阈值判断或时间计算。模拟测试通过，正式客户端受保护值显示和多人同步仍需实测；脱战回放不伪造实时能量。

## 代码基线

V0.8以实际安装的P0前逻辑回退版为基线，仅新增能量显示、分担设置和独立同步。没有重新加载P0诊断或版本检测模块；已有事故存档及audit资料保持原样。历史仓库文档描述的P0后行为不适用于此版本。今晚故障根因仍未确认。

## 调整位置

位置设置 → 文字提示：进入编辑后分别拖动原文字提示与“毒蛇之怒文字”的绿色条，点齿轮调整字号和对齐。两者位置分别保存。
罗盘、发送面板及接收条也可在位置设置中调整。

## 脱战测试

测试页选择职责和速度，开始后运行00:00至06:30；支持暂停、继续、停止、重新开始和跳转。
查看首轮毒蛇之怒：跳转00:20后继续，建议使用1倍速听倒计时。
近战治疗包括奶骑、奶僧；模拟放球只针对远程DPS和远程治疗。毒蛇之怒提醒不受此放球职责筛选影响。
测试发送与接收不会发送团队消息。进入战斗后自动停止测试。

## 语音

本版本继续使用游戏内置 TTS，无需安装额外语音包。

## BOSS图标

位置设置 → 罗盘：预览 / 拖动 / 大小 → BOSS图标透明度，可单独调节，0为隐藏。
图标位于场地标记下层，默认65%。跟随既定带位时间轴显示月亮、星星、中场位置。
短动画表示预定带位方向；到星星后保持该方向，随罗盘旋转一起转向12点。图标不是实时位置探测。
中场图标位于圆心，不改变第四放球点或延后旋转时间。
