# Sszorak Fixed Direction · V0.10

本版本保留罗盘与 Boss 能量值。

- 罗盘按既定时间轴显示场地标记、转向及 Boss 图标。请先面对 Boss，再参考罗盘；图标表示预定带位方向。
- Boss 能量值在史诗斯索拉克战斗中显示当前能量。
- 输入 `/sfd` 或 `/m5` 打开位置设置，分别点击罗盘或 Boss 能量值后拖动，关闭面板完成。沿用原有位置；能量值首次沿用原毒蛇之怒文字下方的位置。
- 暂停放球分配、风向收发、分担配置、倒计时、文字及语音提醒、脱战测试等其他功能。
- 保留原有存档与历史日志。

安装后在下次正常登录或自行安全重新加载插件时生效。
